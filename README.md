# Mineralogy

Mineralogy 6 brings real-world rock types, mineral ores, construction blocks, and crude oil to Minecraft 1.10.2.

## Requirements

- Minecraft 1.10.2
- Minecraft Forge 12.18.3.2511 or later in the 1.10.2 line
- MMD OreSpawn 4.0.6 or newer, below 5.0.0

OreSpawn is Mineralogy's only terrain and deposit engine. Mineralogy supplies content and the packaged provider at `assets/mineralogy/orespawn/provider.json`; it does not register a second chunk generator or replace the Overworld provider.

## Installation

Install Forge, Mineralogy, and OreSpawn in the `mods` folder. Released Mineralogy builds declare OreSpawn as a required dependency.

New worlds use the Mineralogy 6 geome profile with Stable Layers. Existing worlds generated by Mineralogy 3 are detected by OreSpawn and remain on the Cyano/LEGACY terrain profile unless the player explicitly changes their world profile.

## Configuration and upgrades

Content options remain in `config/mineralogy.cfg`. Mineralogy 6 does not delete or rewrite legacy worldgen and ore settings in an existing file.

See the [player guide](docs/PLAYER_GUIDE.md),
[content configuration](docs/CONTENT_CONFIG.md),
[developer guide](docs/DEVELOPER_GUIDE.md), and
[provider reference](docs/PROVIDER.md). On first start, Mineralogy exports the
complete guide and its exact packaged provider to `config/mineralogy-guide/`
without overwriting existing files.

On the first upgraded start, valid non-default legacy ore settings are migrated independently to `config/mineralogy-orespawn.json`. Mineralogy never overwrites an existing provider override or established `config/orespawn-worldgen.json`. The deterministic result is recorded in `config/mineralogy-orespawn-upgrade-report.txt`.

OreSpawn owns terrain profiles and worldgen configuration, including geology mode, formations, ore placement, fluid deposits, and the worldgen UI.

## Crude oil

Mineralogy's fluid is registered as `mineralogy_crude_oil`, with block ID `mineralogy:crude_oil` and bucket ID `mineralogy:crude_oil_bucket`. It is intentionally distinct from Power Advantage's historical global `crude_oil` fluid.

## Texture packs

The default textures are 16×16. Higher-resolution legacy texture packs may be installed as resource packs where compatible.

## Notes for mod authors

All existing Mineralogy block, item, tile, recipe, NBT, asset, and patch-alias identities are retained. Production code now uses the `zone.moddev.mc.mineralogy` package; no deprecated `cyano.mineralogy` Java facade is shipped.

Mineralogy rocks continue to register with the Ore Dictionary as stone and/or cobblestone. Ore-Dictionary recipes remain the recommended integration path.
